# Terra — Павлодар

Рабочая первая версия: карта исследуемой территории, выбор прямоугольной области, поиск летних Sentinel-2 L2A, смена дат и ползунок сравнения.

## Запуск

Из корня проекта: `python -m http.server 4173 --directory dist`, затем открыть `http://localhost:4173`.

Сборка и ключи API не требуются. Авторские исходники находятся в `dist/`, библиотека Leaflet 1.9.4 сохранена в `dist/vendor/` вместе с лицензией.

## Источники и метод

- Метаданные: Microsoft Planetary Computer STAC API, коллекция `sentinel-2-l2a`.
- Изображения: RGB `visual` через TileJSON и Data API той же платформы. Это отображение реальных снимков, не аналитика изменений.
- Подложка: OpenStreetMap; атрибуция сохранена на карте.
- Поиск: июнь–август выбранного года, облачность **всей сцены** менее 30%, до 100 кандидатов каждого года, сортировка по облачности. Геометрия сцены должна содержать углы и центр области. Для стандартных выпуклых контуров Sentinel это отсекает частичное покрытие.
- Повторные сцены одного дня объединяются; выбирается сцена с меньшей облачностью. Начальная пара минимизирует сумму облачности и различие календарных дат (0,15 пункта за день). Пользователь может изменить обе даты.
- Площадь вычисляется по сферической модели Земли, приблизительно. Границы не являются кадастровыми.

## Ограничения

Пилот ограничен Павлодаром и окрестностями. Размер области — от 1 га до 150 км². Разрешение RGB — 10 м; увеличение карты не добавляет деталей. Нет автоматического обнаружения изменений, оценки CO₂, аккаунтов, фонового мониторинга или долговременного хранения участков. Подбор по облачности сцены не гарантирует безоблачность конкретного участка.

Публичные внешние API могут замедляться или быть недоступны; предусмотрены таймауты и состояния ошибок. Для массового коммерческого запуска понадобятся кэширование, наблюдение за доступностью источников и отдельная проверка условий их использования.

В браузерах с поддержкой `document.modelContext` доступны инструменты чтения текущего сравнения и перемещения его границы. При отсутствии поддержки интерфейс работает обычным образом.
