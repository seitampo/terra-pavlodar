# Terra — Павлодар

Веб-приложение для исследования территории Павлодара. «Подробный спутник» показывает здания и помогает выбрать участок; «История» сравнивает датированные снимки Sentinel-2 за два года с помощью ползунка.

## Стек

- **TypeScript** — логика интерфейса, проверка данных и запросы к спутниковому API.
- **HTML и CSS** — адаптивный интерфейс без зависимости от UI-фреймворка.
- **Leaflet** — интерактивная карта и слои снимков.
- **Vite** — локальная разработка и производственная сборка.
- **GitHub Actions / Pages** — проверка типов, сборка и публикация.

Сервер и ключи API для текущих функций не нужны: приложение обращается к открытым источникам непосредственно из браузера. Никаких секретов в клиентский код добавлять нельзя.

## Разработка

Нужен Node.js 22.12+; в автоматической сборке используется Node.js 24.

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm run build
npm run preview
```

`npm run build` проверяет типы и создаёт готовый сайт в `dist/`. Эта папка генерируется заново, исходники в ней редактировать не нужно.

## Структура

```text
index.html                 Разметка и метаданные
src/main.ts                Интерфейс, слои карты и сравнение
src/satellite.ts           Поиск снимков, проверка ответов API
src/detail-imagery.ts      Подробная подложка и метаданные снимка в центре карты
src/geo.ts                 Геометрия, площадь и границы области
src/style.css              Стили и адаптация к экрану
.github/workflows/pages.yml Сборка и публикация
```

## Публикация

В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**. Затем в **Settings → Secrets and variables → Actions → Variables** добавьте переменную `PAGES_ENABLED` со значением `true`. После отправки изменений в `main` workflow соберёт и опубликует сайт. Для pull request выполняется только сборка. Пока публикация не включена, сборка проверяет проект без попытки развернуть сайт.

Сборка использует относительные пути: она подходит для адреса вида `https://username.github.io/terra-pavlodar/` и для собственного домена. Готовую папку `dist/` можно разместить и на другом статическом хостинге.

Возможность Pages для закрытого репозитория зависит от тарифа GitHub. Открытие репозитория делает его исходники общедоступными; это отдельное решение владельца.

## Данные и метод

- [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9): подробная спутниковая подложка через публичный MapServer. Атрибуция Esri и поставщиков сохранена. Изображения загружаются непосредственно в карту, без экспорта или создания собственного архива. Использование подчиняется условиям поставщика, указанным на странице слоя; публичность endpoint не означает открытую лицензию на данные.
- Для подробной подложки отображаются дата съёмки и исходное разрешение **только в точке в центре карты**. Метаданные запрашиваются заново при перемещении и изменении масштаба. Неизвестная дата не заменяется датой публикации карты. Исходное разрешение и шаг отображаемой подложки показаны отдельно.
- В проверенной области Павлодара уровни World Imagery выше z17 возвращают изображения отсутствия данных. Поэтому подробный слой использует `maxNativeZoom: 17`; зум до 19 увеличивает имеющиеся тайлы. Метаданные запрашиваются для фактического уровня тайлов.
- [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/dataset/sentinel-2-l2a): метаданные STAC и реальные RGB-снимки Sentinel-2 L2A через Data API.
- [OpenStreetMap](https://www.openstreetmap.org/copyright): картографическая подложка. Атрибуция сохранена на карте.
- Поиск выполняется за июнь–август выбранного года, с облачностью **всей сцены** менее 30%. Из первых 100 кандидатов, отсортированных по облачности, выбираются сцены, покрывающие область. Дубликаты одного дня объединяются.
- Начальная пара учитывает облачность и близость календарных дат в разных годах. Обе даты можно изменить вручную.
- Площадь рассчитывается приблизительно по сферической модели Земли. Область исследования не является кадастровым участком.

## Ограничения пилота

Павлодар и окрестности; область от 1 га до 150 км². В режиме «История» пространственное разрешение Sentinel-2 — 10 м. Подробная подложка не является снимком выбранного слева года и не используется вместо исторических данных. Увеличение карты сверх доступного разрешения не добавляет деталей. Облачность всей сцены не гарантирует отсутствие облаков над конкретным участком.

Пока нет автоматического обнаружения изменений, оценки CO₂, аккаунтов, фонового мониторинга и долговременного сохранения участков. Внешние API могут быть недоступны; предусмотрены таймауты и сообщения об ошибках.
